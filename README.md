Entry for the make.fun bounty **"Weirdest Job Title: Blind Judge Showdown"**:
https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922

The entry is one job title of 51 characters: a night-shift lighthouse
keeper — for a landlocked town. A job that sounds entirely real, with
one gloriously odd twist: the light guards no sea at all.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.txt — the one title, 1–60 characters, UTF-8
```

`main.py` (Python 3, standard library only) validates the title against
the bounty's gate (1–60 characters, not only white space) and writes it
to `entry.txt` in the output directory.
